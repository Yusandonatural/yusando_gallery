道具一覧 — LIST OF UTENSILS

日本の茶道具一覧

茶の湯で用いられる主な道具の一覧です。詳細ページのある道具は、歴史・部位・使い方・中古選びのポイントまで掘り下げています。

揃えかた — THREE LEVELS

三つのレベルで考える

全部いきなり揃える必要はありません。「今すぐ一服したい」のか、「人を招きたい」のか、「席をしつらえたい」のか。目的ごとに必要な道具は変わります。

LV.1

今すぐ抹茶を楽しむ

自宅で点てる最小のひと揃え

台所にあるお湯で、今日から一服点てられる最小のひと揃え。ここから始めれば十分です。

茶碗茶筅茶杓棗茶入

薄茶は棗、濃茶は茶入に納めます。ほかに茶巾(麻の布)と茶筅くせ直しがあると安心。菓子はふだんの器で構いません。

LV.2

お茶会を開く

点前をして人をもてなす

湯を沸かすところから客の前で行う「点前」の道具。ここまで揃うと、人を招いて一席持てます。

風炉茶釜柄杓帛紗水指建水蓋置菓子器

火は電熱器でも構いません。まずは風炉と釜、水指、建水の四点から少しずつ揃えていきましょう。

LV.3

お茶室を持つ

席そのものをしつらえる

床のしつらえと、炉に火を熾すための道具。季節をかたちにして、席そのものを一つの作品にしていく段階です。

炉掛物花入香合炭斗羽箒火箸灰器茶壺

掛物・花入・香合は「床の三点」。炭斗・羽箒・火箸・灰器は炭点前のひと組で、香合もここに加わります。

茶碗

茶を点て、そのまま口に運ぶ器。亭主の好みと季節がもっとも表れる、茶道具の主役です。

茶筅

ちゃせん / Chasen — Tea Whisk

一本の竹から削り出される、茶を点てるための道具。奈良・高山で五百年続く竹の工芸です。

 03 LV.1まず一服

茶杓

ちゃしゃく / Chashaku — Tea Scoop

抹茶をすくう細身の匙。小さな道具ながら銘を持ち、一席の主題を担う「一番の道具」です。

 04 LV.1まず一服

棗

なつめ / Natsume — Tea Caddy

薄茶用の抹茶を納める漆塗りの容れ物。果実の棗に似たふくらみが名の由来です。

 05 LV.2茶会を開く

茶釜

ちゃがま / Kama — Iron Kettle

湯を沸かす鉄の釜。煮え音は「松風」と呼ばれ、静かな茶室に響く音の主役です。

 06 LV.2茶会を開く

柄杓

ひしゃく / Hishaku — Water Ladle

湯や水を汲む竹の杓。釜から茶碗へ、一筋に注ぐ所作は点前の見せ場のひとつです。

 07 LV.2茶会を開く

帛紗

ふくさ / Fukusa — Silk Cloth

道具を清めるための絹の布。帛紗さばきは、道具とともに心を整える所作です。

釜に足す水、茶碗をすすぐ水を蓄える器。点前座の景色の要となる、どっしりとした存在です。

そのほかの道具

FURTHER UTENSILS — 概説
LV.1まず一服

茶入

ちゃいれ / Chaire — Thick-tea Caddy

濃茶用の抹茶を入れる陶製の小壺。象牙の蓋と仕覆(しふく)と呼ばれる袋に納められ、棗より格上の道具とされます。

LV.2茶会を開く

建水

けんすい / Kensui — Waste-water Bowl

茶碗をすすいだ湯水を受ける器。「こぼし」とも呼ばれ、点前中は客から見えない位置で控えめに働きます。

LV.2茶会を開く

蓋置

ふたおき / Futaoki — Lid Rest

釜の蓋や柄杓を置くための小さな道具。竹の引切りが基本で、青磁や染付など趣向の凝った品も使われます。

LV.3茶室を持つ

香合

こうごう / Kōgō — Incense Container

炭点前で焚く香を納める小さな蓋物。炉の季節は練香に陶器、風炉の季節は白檀に漆器を用います。

LV.3茶室を持つ

花入

はないれ / Hanaire — Flower Vessel

茶席の花を入れる器。竹・青磁・伊賀など。「花は野にあるように」と利休が説いた、席の生命感を担う道具です。

LV.3茶室を持つ

掛物

かけもの / Kakemono — Hanging Scroll

床の間に掛ける書画。禅語の一行物が最も格が高く、「掛物ほど第一の道具はなし」と利休は言い切りました。

LV.2茶会を開く

風炉

ふろ / Furo — Brazier

五月から十月に釜を掛ける持ち運び式の炉。唐銅・土・鉄などがあり、灰形(はいがた)づくりも亭主の腕の見せどころ。

LV.2茶会を開く

菓子器

かしき / Kashiki — Sweets Vessel

茶菓子を盛る器。主菓子には縁高や食籠、干菓子には盆や振出を。菓子は茶の一部といわれる大切な脇役です。

LV.3茶室を持つ

炉

ろ / Ro — Sunken Hearth

十一月から四月、畳を切って設ける囲炉裏。茶室の中心であり、炉を切ることが「茶室を持つ」ことの証でもあります。

LV.3茶室を持つ

炭斗

すみとり / Sumitori — Charcoal Basket

炭点前で炭を運ぶ籠。中に火箸・羽箒・鐶(かん)・香合を仕組んで席へ持ち出します。

LV.3茶室を持つ

羽箒

はぼうき / Habōki — Feather Brush

炉縁や風炉の縁の灰を掃く三枚羽。鶴・鷹・野雁などを用い、炉と風炉で羽の向きを替えます。

LV.3茶室を持つ

火箸

ひばし / Hibashi — Charcoal Tongs

炭をつぐための金属の箸。炉用は柄が長く、風炉用は短め。頭の飾りにも作者の意匠が表れます。

LV.3茶室を持つ

灰器

はいき / Haiki — Ash Container

湿し灰(しめしばい)を盛る素焼きの器。灰匙を添え、炭点前で炉中に灰を撒きます。

LV.3茶室を持つ

茶壺

ちゃつぼ / Chatsubo — Leaf-Tea Jar

葉茶を詰めて保存する大壺。十一月の口切の茶事で封を切り、茶臼で挽いて抹茶にします。茶人の一年はここから始まります。
